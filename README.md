# Movsisyan Beauty Studio — концепт сайта

Пример работы студии **Fieldstone Labs**: одностраничный сайт студии волос в Обнинске с онлайн-записью.

> Не является официальным сайтом студии. Данные из формы записи никуда не отправляются и не сохраняются.
> Сведения о владельце скрыты. Фото и информация об организации взяты из открытой карточки на Яндекс Картах.

## Что внутри

- главная: услуги и цены, работы мастеров, мастера, отзывы, удобства, контакты;
- онлайн-запись в 4 шага: услуга → мастер → дата и время → контакты (маска телефона, валидация, согласия);
- юридические документы: политика обработки ПД, согласие на обработку ПД (152-ФЗ), правила записи и оказания услуг;
- уведомление о cookie, карта Яндекса загружается только по клику;
- адаптивная вёрстка, локальные шрифты (Cormorant Garamond, Manrope — SIL OFL).

## Стек

HTML, CSS, чистый JavaScript — без сборки и зависимостей. Открыть `index.html` в браузере.
